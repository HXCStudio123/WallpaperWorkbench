# WallpaperWorkbench · 桌面工作台壁纸

一个**单文件 HTML** 桌面工作台，可当作 macOS 桌面壁纸（通过 Plash 铺底）或独立应用窗口使用。零外部依赖、零网络请求，数据全部存在本地。

## 功能

- **北京时间时钟 + AI 模型时段排班**：按你定的两家模型规则（智谱 GLM-5.3 / 火山 DeepSeek / Kimi K3），自动高亮「当前时段、推荐模型、成本、该干什么」，带时段进度条与剩余时间；可一键预览周末/工作日。
- **多工作空间切换**：每个空间独立保存待办 / 提醒 / 便签，互不干扰（HUD 左上角下拉切换，编辑模式下可增 / 改名 / 删）。
- **待办 TODO**：随记随看、点击勾选、按时段打标签、悬停删除。
- **提醒**：到点页内弹窗 + 提示音，可开启系统通知（macOS）。
- **随手记**：按空间独立、自动保存。
- **番茄闹钟**：圆环计时、可调专注 / 休息时长、专注标签、按空间统计今日完成数。
- **壁纸背景**：支持图片（含 GIF / 动态 WebP 保留动画）与视频（MP4 静音循环），`填充 / 完整 / 平铺` 三档适配。
- **快捷键**：`E` 编辑 · `T` 主题 · `L` 布局 · `N` 新待办。

## 使用

### 当作桌面壁纸（macOS，推荐）
1. 安装 Plash：`brew install --cask plash`
2. 菜单栏 Plash 图标 → Website → Add Local File → 选择本仓库的 `index.html`
3. 想直接在桌面上点击操作：开启 **Browse mode**（默认快捷键 `⌥⌘B`）

### 当作独立窗口
双击 `open-workbench.command`（用 Chrome `--app` 模式打开，无地址栏 / 标签栏，像一个独立 App）。
想开机自启：把它或 Plash 加入「系统设置 → 通用 → 登录项」。

## 数据
所有数据存在浏览器 `localStorage`（同一 `file://` 源），刷新 / 重启不丢。

## 开发
纯静态单文件，直接编辑 `index.html` 即可。脚本入口做了启动容错：时钟最先渲染、每步独立 `try/catch`，任一模块异常都不会让时间卡住。
